## Freshness rules

Always verify before asserting exact current values for:

- Pricing and Free Tier details.
- Service quotas and API limits.
- Supported Regions or Availability Zones.
- Instance families and service feature availability.
- Public IPv4 pricing/behavior.
- Certification exam versions, retirements, and prerequisites.
- Service deprecations or renames.
- Security guidance that may have changed.
