# Post-task hook

Apply before finalizing Azure build/change, troubleshooting, architecture, security, governance, or production work.

Verify:

1. The answer addresses the stated goal rather than merely describing Azure services.
2. The recommendation follows the relevant local references and current official Microsoft guidance where freshness matters.
3. The solution is no more complex than necessary.
4. Security was not weakened for convenience.
5. Identity and authorization are explicit when relevant.
6. DNS/network path is considered when private networking is involved.
7. Material cost implications are called out without inventing exact prices.
8. Commands use placeholders for unknown real identifiers.
9. Changes include a verification step.
10. High-impact/destructive changes include impact and rollback/recovery guidance.
11. Troubleshooting conclusions are supported by evidence rather than presented as guesses.
12. Language-specific code uses the correct language reference and idiomatic current Azure SDK patterns.
