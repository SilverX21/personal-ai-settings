## Freshness rules

Always verify against current official docs when the request depends on:

- Exact pricing.
- Service limits or quotas.
- Region availability.
- Preview / GA / retirement status.
- Certification exam names or objectives.
- Security recommendations.
- Product renames.
- Azure CLI/API syntax that may have changed.
- Feature availability by SKU/tier.

Do not use a local reference to overrule newer official documentation.
